## What is it?
As it named, it's a web service that allows you translate manga automatically.

## Why using this structure?
My server doesn't have the ability to deploy an ocr service, so I use my computer instead.  
## Techniques  
### Local Deployment  
1. Paddle-OCR for text recognization.
2. opencv-python for text replacement.
3. streamlit for frontend website.
### API  
Balian API for text translation.
